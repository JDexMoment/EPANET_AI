Как работать с этой формой

  1. Шаг 0. Прочитайте краткую инструкцию внизу страницы (нажмите «Свернуть подсказки», если мешает).
  2. Шаг 1. Разметка сценария. Оцените, есть ли проблема, и поставьте метку. Смотрите только на данные: таблицы KPI, алерты, evidence — это ровно то, что увидит модель.
  3. Шаг 2. Эталонные ответы. Для каждого вопроса заполните поля. Каждое число — с ссылкой вида E-007 на факт из таблицы.
  4. Шаг 3. Probe-вопросы — обязательные короткие уточнения (наблюдения / причины / ограничения).
  5. Шаг 4. Сверка. Нажмите «Показать, что внесено в модель» и проверьте: совпала ли ваша версия с внесённой неисправностью. Если нет — напишите, что сбило с толку: это ценные данные.
  6. Шаг 5. Экспорт. Кнопка «Экспорт JSON сценария» → файл сохраните в data/cases/inbox/. Всё, что не дописано, отметить недостаточно данных нельзя — вместо этого укажите, каких данных не хватает.

Форма работает офлайн, данные сохраняются в браузере по кнопке. Ничего не отправляется в интернет.
