Разметка экранов — «что находится на экране»

Инструмент для создания бенчмарка понимания интерфейса: скриншот → эталонный JSON. Ничего никуда не отправляется: файл картинки не покидает ваш компьютер.

1. Скриншот

Перетащите сюда PNG/JPG скриншот
или нажмите, чтобы выбрать файл
ID заполняется из имени файла — при необходимости поправьте. Файл не встраивается в JSON (в JSON попадут только метаданные о нём).

2. Что на экране (эталон)

Если на экране нет явно выбранного объекта — оставьте поле пустым. Это самый важный ответ: он определяет, должна ли модель уточнять у пользователя.
IDЗначениеЕд.
Файл сохранится как screen_<ID>.json — положите его в data/screen_labels/, скриншот — в data/screen_labels/screenshots/.
