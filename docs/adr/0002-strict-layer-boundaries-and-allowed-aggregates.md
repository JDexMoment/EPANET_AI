# ADR-0002: Граница между запрещёнными гидравлическими пересчётами и допустимыми описательными агрегатами

- **Статус:** Принято
- **Дата:** 2026-10-30
- **Этап:** Этап 0 / Этап 4 / Этап 5

## Контекст

Главный архитектурный инвариант проекта (§1.1–1.4): **вся гидравлика считается исключительно в расчётном ядре AquaBit**. Любая попытка пересчитать в Python или в LLM потери напора (Hazen-Williams / Darcy-Weisbach), скорости по расходу и диаметру, уровни резервуаров или рабочие точки насосов приведёт к расхождению с сертифицированным расчётным ядром AquaBit и потере доверия инженеров.

В то же время LLM не должна читать сырые таблицы временных рядов и не умеет надёжно агрегировать тысячи строк без галлюцинаций.

## Решение

Вводится жёсткое трёхслойное разделение ответственности:

1. **Ядро AquaBit (внешний источник истины):** вычисляет все физические величины (`head_m`, `flow_m3_h`, `velocity_m_s`, `level_m`, `state`). Если поле отсутствует в выгрузке, оно не довычисляется в Python (фиксируется пропуск в `facts_skipped.jsonl` либо `is_null: true` в диагностике).
2. **Python-слой (`preprocess` + `facts` + `trace`):** выполняет **исключительно**:
   - нормализацию структуры, единиц измерения (линейный перевод размерностей при явной записи `unit_converted=true`) и типов;
   - тривиальные описательные агрегаты по готовым рядам AquaBit: `min`, `max`, `mean`, `sum`, `count`, `duration` (`count * step_h`), арифметическую разность уже готовых балансовых итогов (`total_supply - total_demand`) и геометрическую проверку принадлежности готовой точки `(Q, H)` паспортной ломаной `pump_curves.csv` (при наличии ≥3 точек).
   - оборачивание каждого числа в `TracedFact` с обязательными полями `unit`, `source = {file, field, aggregation, ...}` и `quality`.
3. **LLM-слой (`llm`):** получает только сериализованный набор фактов (`facts_inline` + `manifest`), формирует инженерный текст и обязана ссылаться только на числа, присутствующие во входных фактах с совпадающим значением и единицей.

## Последствия

- Исключено расхождение между расчётом AquaBit и числами в `report.html` / `facts.jsonl`.
- Пост-валидатор Этапа 6 и Этапа 7 может детерминированно (за $O(N)$) проверить 100% чисел в ответе учителя и студента на `hallucinated_numbers == 0`.
