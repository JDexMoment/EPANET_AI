# ADR-0001: Выбор `pandas` + `PyArrow` (nullable dtypes) в качестве табличного движка

- **Статус:** Принято
- **Дата:** 2026-10-30
- **Этап:** Этап 0 (Scaffolding) / Этап 1 (Ingestion) / Этап 3 (Preprocessing)

## Контекст

Модуль `aquabit-ai` обрабатывает табличные CSV-выгрузки гидравлической сети из AquaBit и сохраняет нормализованные таблицы в `normalized/*.parquet`. При этом действуют жёсткие инварианты ТЗ (§1):
1. Пропуски ≠ нули: пустое значение в CSV обязано стать `null`, а `"0"` — сохраниться как `0.0`.
2. Идентификаторы (`id`, `start_node_id`, `curve_id` и др.) — строго строки с сохранением ведущих нулей (`"0042"`) и буквенных префиксов.
3. На Этапе 1 (Ingestion) любая автотипизация и заполнение пропусков запрещены.

Рассматривались два варианта из ТЗ (§4, Этап 0): `Polars` и `pandas + PyArrow`.

## Решение

По согласованию с заказчиком выбран стек **`pandas >= 2.2` + `pyarrow >= 17.0`** со следующими обязательными правилами использования в коде:

1. **На Этапе 1 (Ingestion)** чтение CSV выполняется строго с параметрами:
   ```python
   pd.read_csv(..., dtype=str, keep_default_na=False, na_filter=False, index_col=False)
   ```
   Это полностью отключает вывод типов `pandas`, предотвращает превращение `"001"` в `1` и не позволяет `pandas` конвертировать `""` или строковые коды вроде `"NA"` в `float('nan')`.
2. **На Этапе 3 (Preprocessing)** колонки переводятся в **nullable / Arrow-backed типы** (`pd.StringDtype()`, `pd.Float64Dtype()`, `pd.Int64Dtype()`, `pd.BooleanDtype()`), где отсутствие значения представлено `pd.NA` (сериализуемым в Parquet `null` и JSON `null`), а `0.0` остаётся вещественным нулём.
3. **Сериализация Parquet** выполняется через движок `pyarrow` (`df.to_parquet(..., engine="pyarrow", index=False)`), гарантируя сохранение строгой схемы и `null`-масок между этапами.

## Последствия

- **Плюсы:** высокая совместимость с инженерным Python-стеком команды AquaBit; прозрачная интеграция с `pyarrow`, `pytest`, `matplotlib`/`plotly`.
- **Риски и защита:** стандартный вызов `pd.read_csv(path)` без защитных флагов нарушил бы инварианты §1.6 и §1.7. Поэтому прямое чтение CSV вне модуля `aquabit_ai.ingest` запрещено и контролируется юнит-тестами (`test_stage1_ingest.py`).
